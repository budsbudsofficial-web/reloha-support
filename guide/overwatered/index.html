RELOHA JOURNAL / 根のトラブル

湿った土と、元気のない葉。根を疑う前の確認。

水はあるのに、葉に元気がない。そんなときは、さらに水を足す前に、根の周りで何が起きているかを確かめましょう。

RELOHA編集部 · 2026年10月23日 更新

まず、結論

土が何日乾かないかだけでは、根腐れを確定できません。たまり水と排水を確認し、しおれや黄変、株元の軟化などを合わせて見ます。根が柔らかく崩れるなどの異常がある場合は、傷みの程度に応じた植え直しや相談が必要です。

今日やることは、この3つ

  1. 受け皿・鉢カバーの水を捨て、追加の水やりをいったん止める。
  2. 土の中・葉・株元を確認し、異常の範囲を記録する。
  3. 根の点検が必要か判断し、傷みが進む株は早めに相談する。

この記事でわかること

  1. 「過湿」と「根腐れ」を、同じ意味にしない
  2. 根を抜く前にできる、最初の対処
  3. 根の点検が必要なときは、無理なく一度に
  4. 植え直す場合と、救出が難しい場合
  5. 再発を防ぐには、水やりの理由を見直す
  6. よくある質問

「過湿」と「根腐れ」を、同じ意味にしない

用土が湿りすぎている状態と、実際に根が傷んでいる状態は分けて考えます。根の周りに余分な水分が続くことは問題になりますが、葉が黄色い、鉢が重いという一つの情報だけで病名までは決まりません。［1］

根の色は種類や用土でも違うため、「茶色＝すべて腐っている」とは限りません。張り・硬さ・崩れ方などを合わせて見ます。写真だけで確定することも避けましょう。［2］

根を抜く前にできる、最初の対処

  1. 鉢カバーや受け皿の水を捨て、鉢底が水に浸からないようにする。
  2. 排水穴がふさがれていないか、容器に穴があるかを確認する。
  3. 追加の水や肥料を控え、植物に合う明るさ・温度で管理する。
  4. 葉、根元、土を撮り、水やり・施肥・移動の履歴を整理する。

「乾かせば治る」と考えて、強い直射日光、ドライヤー、暖房の直風で急に乾燥させるのは避けます。葉への負担を増やし、問題を重ねることがあります。

表面だけが乾いても、中が湿っていれば追加の水は慎重に。逆に、根の確認が必要な状態を「自然に乾くまで」と長く放置することも避けます。判断は日数ではなく、症状の進行と根元の状態を重視します。

根の点検が必要なときは、無理なく一度に

湿った土で症状が続く、株元に異常がある、排水の問題が解消できない場合は、根鉢を確認する必要があります。大型株や根が鉢に強く張り付いた株を、茎だけ持って引き抜かないでください。安全に扱えない場合は購入店へ相談します。［2］

  1. 作業前に道具と作業面を清潔にし、他の鉢に汚れた用土や水が広がらないようにする。
  2. 株と根鉢を支え、可能なら鉢からそっと外す。
  3. 根の色だけでなく、柔らかさ・崩れ・健全な根が残っているかを見る。
  4. 根の傷みと株元の範囲を写真で残し、次の処置を決める。

確認のために何度も根を裸にしたり、健康な根まで一律に洗い落としたりしないようにします。根を扱う負担も含め、植え直しが必要かを判断します。

植え直す場合と、救出が難しい場合

傷んだ根があり健全な部分が残る場合、清潔な道具で傷んだ部分を取り除き、新しい適切な用土へ植え直す対応が考えられます。ただし種類や傷みで手順が異なり、回復は保証できません。根や株元の傷みが大きい株は、作業前に相談する方が確実です。［2］

根が減った株を「回復用」として大きすぎる鉢に入れると、用土が過剰に水を抱える場合があります。残る根量に合う鉢底穴のある鉢と、植物に合う用土を選びます。植え直し後の水やりも、すべての植物を同じ日数で断水させるのではなく、種類と処置に合わせて確認してください。［3］

株元まで広く腐敗している場合は、元の株の救出が難しいことがあります。挿し木などで残せるかも種類と健全部の有無次第です。病気の疑いのある部分を、他の植物と同じ水や容器で管理しないようにします。

薬剤は根腐れらしい見た目だけで選びません。使用する場合は日本での適用植物・対象病害・ラベルを確認し、自己流の漂白剤や薬液に根を浸す方法は勧めません。

再発を防ぐには、水やりの理由を見直す

鉢の大きさ、用土、置き場所、生育期を見直し、「前の鉢と同じ曜日に水を与える」をやめて実際の乾湿を確認します。植え直しの日、水を与えた理由、根元の変化を記録すると、同じ問題を繰り返したか判断しやすくなります。

  • 排水後に鉢カバーへ水が戻っていないか。
  • 寒く暗い時期も、夏と同じ間隔で与えていないか。
  • 少量の継ぎ足しで、いつも湿った状態になっていないか。
  • 新しい黄変・軟化が増えていないか。

改善は古い葉の色が戻るかだけでなく、新しい傷みが止まるか、新芽や根元に張りがあるかを見ます。悪化が続く場合は写真と履歴を添えて相談してください。

よくある質問

土が一週間乾かないと根腐れですか？

それだけでは決まりません。鉢・用土・光・気温で乾く速さは変わります。症状、排水、根の状態を合わせて見ます。

乾燥させるだけで回復できますか？

過湿の修正が必要でも、傷んだ根が元に戻るとは限りません。進行や根元の状態によっては植え直しや相談が必要です。

黒い根は全部切っていいですか？

根の色だけで一律に切らないでください。柔らかく崩れるか、張りがあるかも確認し、判断が難しければ相談します。

肥料や活力剤で元気を戻せますか？

排水や根の傷みの問題そのものは解決しません。原因が分からないまま追加せず、まず根と管理条件を確認します。
